# ClinicTrack · client (React + Vite)

React SPA for ClinicTrack — built in **Phase 3** (layout, auth, patients,
visits, timeline, diff viewer, prescription builder) and **Phase 4**
(analytics, live queue, audit log).

Design tokens live in a shared `theme.css` (see the root README for the
color system: primary `#2563EB`, page `#F1F5F9`, etc.) with a dark-mode
toggle.
