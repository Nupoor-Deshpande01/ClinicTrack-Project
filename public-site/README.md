# ClinicTrack · Public Website

Static Bootstrap 5 website for **Siddhivinayak Clinic** — built in **Phase 1**.
It will contain the landing page, an appointment request form with vanilla
JavaScript validation, a rule-based chat window, and a `tools.html` page
(BMI calculator, paediatric dose calculator, slot picker).

Deployment target: Apache Tomcat (drop the folder into `webapps/` or package
it as a WAR — see `../docs/TOMCAT_SETUP.md` once Phase 1 is done).
