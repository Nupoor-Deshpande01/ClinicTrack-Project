# Serving the public-site with Apache Tomcat

Step-by-step guide written in **Phase 1**, covering:

1. Installing Apache Tomcat 10/11 on Windows and Linux.
2. Deploying `public-site/` into `webapps/` (copy method).
3. Packaging `public-site/` as a `clinictrack.war` and deploying it.
4. Verifying at `http://localhost:8080/clinictrack/`.
